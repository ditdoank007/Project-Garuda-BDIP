# GARUDA KNOWLEDGE

## Purpose

GARUDA KNOWLEDGE is the central knowledge base for Project Garuda.

Every important lesson, troubleshooting step, infrastructure configuration, and engineering experience must be documented here.

The objective is simple:

> Solve a problem once.
> Document it.
> Never solve the same problem twice.
