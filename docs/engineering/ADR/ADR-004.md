# ADR-004

## Title

Generic Search Engine using React Hooks

---

## Status

Accepted

---

## Context

Multiple modules require client-side searching.

Duplicating search logic in every page would increase maintenance cost.

---

## Decision

Project Garuda will use reusable React Hooks:

* useSmartSearch()
* useDebounce()

All searchable modules should reuse these hooks.

---

## Consequences

Advantages

* reusable
* type-safe
* consistent
* easier testing
* lower maintenance

Disadvantages

* initial abstraction required
